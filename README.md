🌐 My Portfolio Website

This is my personal portfolio website built using HTML and CSS. I created this project to practice front-end fundamentals and to showcase a simple introduction about myself, my interests, and a few sample projects.

The website includes two pages: a Home page and a Contact page, connected through easy navigation.

📌 About This Project

I built this project as part of my learning journey in web development. It helped me understand:

How to structure web pages using HTML 🧱

How to style layouts using CSS 🎨

How to create clean and reusable sections

How to link multiple pages together 🔗

This project focuses only on HTML and CSS, without using any frameworks or JavaScript.
